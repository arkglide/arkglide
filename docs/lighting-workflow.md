# 静态光照制作

停止运行，选中固定的网格或模型，打开「菜单 → 静态光照烘焙…」。选择每个网格的分辨率、AO 射线数、世界距离和表面偏移，点击开始。生成的 PNG 自动成为项目贴图，接收面获得独立 PBR 材质；保存、剪贴板和独立导出沿用已有资源系统。一次撤销恢复全部生成资源和绑定。

计算在可取消的工作线程中进行，C++/WASM 构建场景 BVH，再批量追踪方向光、点光和半球环境的阴影/AO。输出是线性漫反射光照，峰值通过材质倍率保留，不将大于 1 的亮度直接裁掉。运行时与当前基础色、纹理和金属度结合，PBR 环境贴图继续提供原有环境光照和反射。

## 接收面与 UV

- 基础几何自动生成独立 UV2，保留原表面 UV。盒体和圆柱采用分区图集，球体、胶囊和圆环使用归一化的连续参数化。
- 导入模型需要预先生成不重叠的 0–1 UV2，并给部件分配编辑器自有 PBR 材质。工具检查顶点/法线、范围、重叠和当前分辨率下的有效像素。它不会为任意模型自动展开 UV。
- 接收面和父级不得有脚本、动画、角色或动态/运动学物理。骨骼、morph、透明与透射表面不作为接收面；隐藏、动态或透明的几何不作为遮挡物。遮挡按不透明三角形双面计算，不模拟裁切纹理。
- 单次最多 4 MP 接收像素、100 万遮挡三角形、256 盏灯。分辨率过低的小 UV 岛仍应在 DCC 中整理，或提高分辨率。

这轮提供静态漫反射直射与环境 AO，不计算多次反弹 GI、发光纹理照明、IBL 烘焙或动态物体的光照转移。点光按距离平方衰减。与实时材质相比，采样、光源近场和高光处理会有差异。

## 调整与重新烘焙

已烘焙材质的「烘焙直射光（关闭实时直射）」默认开启，避免同一组直射光重复叠加；它关闭该材质的全部实时直射，也包括后来添加的动态灯光。可以在材质面板关闭这一设置进行对照。移除光照图时自动恢复实时直射。

移动几何、父级或灯光后应重新烘焙，烘焙窗口会显示场景变化提示。结果使用场景快照；计算期间更换项目、编辑场景、替换资源或开始播放，旧结果不会写回。取消会终止整个工作线程，保留原项目。

## 室外级联阴影

在「项目设置 → 画面与光照」启用实时软阴影，再开启「方向光级联阴影（室外）」。可选 2–4 级、均匀/对数分割权重、边界过渡和稳定边缘。阴影距离控制覆盖范围；每级使用设置的阴影分辨率，因此级数会增加显存和绘制开销。

仅方向光使用级联；点光保留原立方体阴影，不支持 CSM 的设备回退普通阴影。级联绑定主相机，换主相机时重建。传送门和镜面沿用主视图阴影覆盖，不为每个虚拟视点创建独立级联。停止和关闭时释放全部分层阴影目标。
