# 静态实例批次

在基础网格属性中开启「静态实例批次」。相同基础几何、自有 PBR 材质、投射/接收阴影设置的对象自动形成原生硬件实例批次。几何共享节省顶点/索引缓冲；实例批次进一步降低绘制调用。实例保留自己的节点 ID、父子变换、可见性、拾取和静态碰撞。

```json
{ "optimization": { "instancing": true } }
```

旧项目默认关闭以保留对象类型。开启后，节点背后的渲染对象是 Babylon `InstancedMesh`；隐藏的源网格归场景适配器所有。成员删除不会释放仍在使用的材质和贴图，最后一个成员删除时释放内部源；清空场景和直接销毁源都支持完整清理。

首版支持不透明和裁切 PBR 基础网格，包括清漆、织物、各向异性和细节图等共享表面设置。支持普通/级联阴影、GPU 体积深度与遮挡，以及静态网格碰撞。运行中可以独立移动、旋转、隐藏和拾取成员；一组成员共用材质参数。

以下组合保守回退普通网格，诊断显示回退数量：

- 导入模型、缺少自有 PBR 材质、关闭几何共享；
- 自身或父级包含脚本、动画、角色、动态/运动学物理或非正缩放；
- 透明/透射、光照图或烘焙元数据；
- 项目有局部反射探针、节点启用平面反射，或启用静态 LOD。

材质、阴影标记或适用条件改变后，下一次场景同步会重建分组。编辑器自动同步；宿主直接调用渲染配置 API 修改探针后，也须同步场景。原生实例渲染继续使用已有 WASM 批量变换与剔除路径，矩阵缓冲提交由 GPU 实例管线处理。

「菜单 → 场景性能基准 → 普通网格 / 实例批次」使用相同原始几何与相机轨迹对照。CLI 使用 `BENCH_INSTANCING=1 npm run benchmark:scene:browser`。报告给出实际绘制调用、主视图三角形、批次数、成员数和回退数，不能用逻辑成员数量推算 FPS。

真实 WebGL 用例中，64 个方块与地面从 65 次绘制降为 2 次，画面像素一致；同时启用阴影和体积大气时也保持一致。目标设备的帧率仍须本机测量。

导入 [instance-lab.arkglide](../examples/instance-lab.arkglide) 查看 24 个石构物体共享一批的柱廊。示例保留体积光束，并为实例化地面创建真实 Jolt 静态三角碰撞体；`V` 对照体积效果，`1/2/3` 切换质量。
