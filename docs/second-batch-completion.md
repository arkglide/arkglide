# 第二批补齐：分部件材质、嵌套预制体与运行时生成

本版继续第二批 F15/F16，保留全部编辑器、生命周期、恢复和诊断功能。项目格式升级为 **0.4**，兼容无版本标记及 0.1/0.2/0.3；旧项目不需要手工转换。模型材质槽与嵌套映射进入撤销、IndexedDB、自动恢复和 `.arkglide` ZIP。

## 模型分部件材质

选择导入的 GLB/glTF 模型，右侧「模型分部件材质」会列出真实网格及材质槽。显示名称用于阅读，引用使用 `mesh:<导入序号>/slot:<槽序号>`，因此同名部件不会混淆。

每个槽有三种状态：

| 状态 | 行为 |
| --- | --- |
| 跟随整体材质 | 使用节点整体项目材质；未设置整体材质时使用模型原始材质 |
| 使用此部件原始材质 | 显式恢复该槽的导入材质，即使整体材质仍被覆盖 |
| 选择项目材质 | 仅覆盖当前槽，继续共享项目材质定义 |

支持 Babylon MultiMaterial 的独立子材质槽，包装对象由适配器管理；删除一个模型不会释放另一个物体使用的项目材质。解除槽覆盖会恢复原始材质，撤销/重做保留赋值。预制体更新按槽进行三方合并，其他槽可以继续接收模板更新。

资源页可创建项目材质或独立副本，再在槽中选择。重新链接**不同结构**的模型后，导入序号可能改变，应检查材质槽；缺失槽会在属性面板保留并显示提示，可改为「跟随整体材质」删除覆盖。这不是模型格式内部的永久 GUID。

## 嵌套预制体

1. 从一个实体子树创建子预制体，例如 `Weapon`。
2. 新建普通父节点，例如 `Soldier`，把 `Weapon` 实例拖到父节点下面。
3. 从 `Soldier` 创建预制体。子实例关联会保留，不需要解除关联。
4. 生成 `Soldier` 实例时，会创建新的外层与子层实例记录和独立实体 ID。
5. 修改子实例后「应用到模板」，会更新子模板、依赖它的父模板以及场景实例；已有本地属性、逐轴变换、材质槽覆盖和本地删除继续保留。

可继续组合多层，例如 `Team → Soldier → Weapon`。最多支持 64 层；禁止循环依赖。子模板仍被父模板引用时不能删除，即使场景实例全部删除，模板自己的模型快照仍保留。

选择子实例可以通过「选择外层预制体」切换到父实例。嵌套根的位置是挂载位置；应用子模板不会把挂载位置带到其他独立子实例。修改父实例后应用到父模板，可以保存父模板配置的子节点覆盖，同时保留子模板的独立定义。

### 更新、重置和解除关联

- 更新子模板按依赖顺序刷新父模板快照，再合并到场景；新增/删除的子节点也会传播。
- 「重置覆盖」恢复所选模板的继承内容，恢复被本地删除的继承节点，保留根放置位置和场景自行新增的节点。重置外层实例会恢复模板中的嵌套关联。
- 解除外层关联保留内层实例。解除内层关联会让这些节点由外层实例管理，并登记已解除的挂载点；应用外层模板后，其他外层实例也会解除该嵌套关系。
- 复制完整外层实例会复制所有嵌套关联；复制一个完整内层根也会保留该内层实例，可作为父实例中的场景新增内容。只复制普通继承子节点会解除其原有实例关联。
- 内部剪贴板保留递归依赖的模板、模型、材质与贴图；粘贴会恢复已删除依赖，保留仍存在的资源定义。
- 将继承节点移出外层实例前，需要解除对应外层关联；这避免模板映射留下悬空节点。

当前提供嵌套关联及属性覆盖，不包含模板继承/变体编辑器、对象池或独立 `.prefab` 文件格式。

## 运行时生成 API

脚本工厂新增 `prefabs` 注入，Monaco JS/TS 提示包含参数、Promise 返回值和句柄类型。模板 ID 在资源面板可查看，名称不保证唯一；`findByName` 返回第一个匹配模板，正式项目推荐保存稳定 ID。

```js
return defineScript({
  onStart() {
    const template = prefabs.findByName('Soldier');
    if (!template) return;
    prefabs.instantiate(template.id, {
      position: { x: 2, y: 0, z: 0 },
      rotation: { x: 0, y: Math.PI, z: 0 },
      scale: { x: 1, y: 1, z: 1 },
      // parent: this.entity, // 可选；变换为父实体的局部坐标
    }).then(instance => {
      console.log('生成完成', instance.root.id);
      const weapon = instance.findByName('Weapon');
      if (weapon) weapon.visible = true;
      // instance.destroy(); // 销毁根、全部后代与脚本资源
    }).catch(error => {
      if (error.name !== 'AbortError') console.error(error);
    });
  }
});
```

| API | 行为 |
| --- | --- |
| `prefabs.list()` | 模板 ID、名称、版本、节点数的普通对象副本 |
| `prefabs.findByName(name)` | 第一项描述对象，缺失返回 null |
| `prefabs.instantiate(id, options?)` | 异步加载模型，建立实体与所有脚本工厂，按父节点优先执行 `onStart` 后返回句柄 |
| `handle.root` | 根实体句柄 |
| `handle.entities` | 创建后仍存活的实体句柄只读数组 |
| `handle.find(localNodeId)` | 按外层模板本地节点 ID 查找；已销毁时返回 null |
| `handle.findByName(name)` | 在该实例范围查找第一项；不查到其他实例 |
| `handle.destroy()` | 销毁根和后代，重复调用安全 |

未指定位置/旋转/缩放时使用模板根定义。可用 `parent` 挂到当前运行的实体；无效变换、不存在的模板或缺失模型依赖在变更场景前拒绝。模型加载失败会拒绝生成并清理已创建内容。

新增实例使用当前运行的生命周期和时钟，不重置已有实体的脚本状态、实时变换或累计时间。运行暂停时允许完成生成及 `onStart`，逐帧/固定步/计时器仍保持暂停；渲染资源加载不依赖模拟时间。

停止运行、销毁生成过程的父实体，或销毁发起生成的脚本实例，会立即以 `AbortError` 拒绝未完成的生成。迟到的模型容器不会加入场景。已完成的生成实体有独立生命周期，不会因发起脚本销毁而自动删除；需要显式销毁实体或停止运行。

生成物只存在于运行沙箱，停止后释放；不写回编辑器和保存文档。模板专用模型也传入沙箱，删除最初的场景来源后仍能动态生成。反复生成/销毁时，脚本记录会从会话中移除，模型缓冲区随实体释放，项目共享材质在运行停止时统一释放。
