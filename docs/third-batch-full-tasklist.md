# 第三批完整能力任务单

## 目标与完成口径

用户脚本采用 JavaScript，不增加 TypeScript 编译要求。本轮项目内 `import/export` 为已完成的基础设施。第三批基础玩法已完成；下面列的是尚未实现的进阶任务，**所有未勾选项都属于计划，不是交付承诺已完成**。

第三批完整能力的范围为 F11 物理、F18 动画、F19 音频、F20 游戏 UI 与输入，以及它们的编辑、保存、运行和清理闭环。F10 性能优化、F12 C++ 场景图、F13 静态发布、F14 联机不纳入这份任务单。复杂软体/布料、车辆模拟、完整骨骼动画制作工具、着色器图另行规划。

- [x] JS-01 项目内静态导入、转导出、字面量动态导入；旧脚本兼容、实例工厂、模块补全、预制体预加载、错误定位与重命名联动。

每个子批次都交付完整源码、中文变更说明、示例和验收记录。默认不提交或推送 Git。

## 实施顺序与最终验收

顺序为 **3A → 3B → 3C → 3D → 集成验收**。每批可以独立交付，C-01～C-05 随每批推进，最后对整套系统再验收一次。

第三批只有在 P/A/S/U 全部任务与 C 共用要求完成后，才从「基础目标完成」改为「本任务单完整目标完成」。验收示例必须同时具备模型碰撞与角色控制、动画状态/混合/事件、分组与流式音频、可编辑 UI、三类设备输入，项目保存/迁移与重复运行后仍可复现。
