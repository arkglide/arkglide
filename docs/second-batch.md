# 第二批：材质、贴图与预制体

本文件记录第二批初版；分部件材质、嵌套关联和运行时生成的补齐规则见 [second-batch-completion.md](second-batch-completion.md)。

这一批完成 F15 的项目材质/贴图链路，以及 F16 的编辑器预制体模板、实例、覆盖和更新。保留第一批的生命周期、自动恢复、运行诊断与前一轮编辑器修复。

## 材质与贴图

底部打开「材质与预制体」，分别进入「材质」「贴图」「预制体」。选中网格或模型后，也可以在右侧属性面板新建和绑定材质。

- 材质使用 Babylon PBR，支持基础色、自发光色、金属度、粗糙度、透明度、双面渲染和 UV 重复比例。
- 支持 PNG、JPEG、WebP 的颜色、法线、金属粗糙度贴图；单张资源最大 64 MiB。导入前解码校验，损坏的图像不会替换已有贴图。颜色贴图使用 sRGB，法线和金属粗糙度贴图使用线性空间。金属粗糙度图 G 通道为粗糙度、B 通道为金属度。
- 「项目资源」中的图片可点击导入项目；也可直接在贴图页选择文件。导入后的内容由项目保存，不依赖原目录继续存在。
- 材质按资源 ID 共享。修改材质会影响所有引用它的物体；「材质独立副本」可为某个节点创建独立定义。
- 网格未绑定项目材质时沿用节点颜色；模型未绑定时沿用 GLB/glTF 原始材质。绑定项目材质会覆盖模型的全部网格部件，解除绑定会恢复原材质。本版已补齐分部件材质槽编辑，操作见补齐说明。
- 材质正在被场景、模板或实例基线引用时不能删除；贴图正在被材质引用时不能删除。先解除引用，再删除资源。
- 替换贴图保留 ID 和所有材质引用；缺失贴图保留元数据并在贴图页提示，可使用「重新链接贴图」补回。替换和删除可以撤销。

共享的项目材质和贴图由场景适配器集中管理，删除一个物体不会释放其他物体仍使用的材质。停止运行会释放运行沙箱中的项目材质、贴图和模型；编辑器二进制保留，不会被 postMessage 转移清空。模板资源与编辑资源都进入保存、恢复和导出链路。

## 预制体

1. 建好实体子树，可以含网格、模型、空节点、灯光、相机和脚本绑定。
2. 选中根节点，点击属性面板「创建预制体」，或预制体页「从选中子树创建预制体」。原子树会成为第一个实例。
3. 点击「生成实例」。各实例有独立节点 ID、变换、脚本工厂状态和模型缓冲区；材质定义仍按 ID 共享。
4. 改动某个实例后，在属性面板点击「应用到模板」。模板版本递增，其他关联实例同步更新。
5. 「重置覆盖」回到当前模板；「解除关联」保留场景子树，之后作为普通节点编辑。仍有关联实例的模板不能直接删除。

模型模板保存独立的二进制副本；删除最初的场景物体后，模板仍能继续生成实例。若模板模型丢失，先生成/选择模型实例重新链接，再应用到模板。复制整个实例根节点（Ctrl+D、复制粘贴）会创建新的关联实例；只复制实例中的子节点会生成普通节点。内部剪贴板保留所需资源快照；复制后删除原模板、材质或贴图，再粘贴可恢复已删除的依赖，仍存在的资源使用当前定义。

### 覆盖规则

更新以「上次应用的模板」「当前实例」「新模板」进行三方合并：

| 属性或结构 | 更新后的行为 |
| --- | --- |
| 实例根节点的位置和外部父节点 | 始终保留，作为实例的放置位置 |
| 位置、旋转、缩放的子节点分量，根节点旋转/缩放 | 每个轴独立保留本地覆盖，其他轴接受模板更新 |
| 名称、可见性、材质 ID、脚本绑定、几何类型等属性 | 实例改过的属性保留，未改的接受更新 |
| 同文件名的模型重新链接 | 模型修订标记参与合并；本地替换保留，未替换的实例接收新模型 |
| 模板新增节点 | 添加到其他实例；若其祖先被实例本地删除，则保持删除 |
| 实例删除的继承节点 | 更新后继续保持删除；重置覆盖时重建 |
| 模板删除的继承节点 | 从关联实例删除；实例自行新增的子节点保留并挂回实例根节点 |
| 实例自行新增的节点 | 保留；从此实例应用到模板后，这些节点成为模板内容 |
| 重置覆盖 | 重置继承节点属性并恢复本地删除，保留根节点放置位置和自行新增的节点 |

应用到模板时，作为来源的实例成为新基线。属性面板显示改动节点、删除节点、新增节点的数量。材质定义是共享资源，修改定义本身不会计入节点的覆盖数量；更换节点的材质 ID 才是节点覆盖。脚本重命名和删除会同步场景绑定、模板、实例基线与内部剪贴板。

初版采用平面模板；本版已补齐嵌套关联与运行时动态生成，具体更新、重置和解除关联规则见补齐说明。模板继承/变体和独立预制体文件格式仍留待后续。

## 保存与兼容

项目格式升级到 **0.4**。兼容无版本标记、0.1、0.2 和 0.3 的旧项目；旧项目获得空资源库。未知新版本、无效材质参数、缺失的元数据引用、损坏的实例映射和循环层级会在替换文档前拒绝。

IndexedDB 的纹理数据采用项目 ID 隔离，项目元数据、场景/模板模型与贴图在一个事务中保存；自动恢复记录包含它们的完整快照。`.arkglide` ZIP 内有 `project.json`、`assets/` 模型、`textures/` 贴图，包含只被模板引用的模型。模型同名会重命名打包，缺失资源不会误读其他同名模型。

新增材质、贴图与模板操作都进入撤销历史；新建、加载、导入、恢复项目清空旧历史和剪贴板。播放或暂停期间禁止修改本批项目资源，停止后恢复编辑。

## 本阶段的后续边界

F15 不含着色器图、纹理绘制、独立 UV 展开、KTX2 等压缩贴图离线解码和 IBL 环境资源面板。F16 现已包含运行时动态生成和嵌套预制体，对象池留待后续。动画、音频、物理、游戏 UI 和独立可玩导出仍由后续阶段实现。
