# 大气、特效与高级材质

这些功能共用于编辑器、播放预览和独立包。项目设置位于「菜单 → 项目设置 → 画面与光照」，材质参数位于节点的「共享材质」或资源材质编辑器。旧项目默认关闭新增效果。

## 雾和程序天空

雾支持线性、指数和指数平方三种模式。线性雾以世界距离的起点/终点控制；指数雾以密度控制，密度为零没有衰减。雾作用于支持 Babylon 原生雾的场景材质，包括自有 PBR 和普通导入模型。本轮提供距离雾，不是三维体积光或带高度积分的体积雾。

程序天空使用不依赖贴图的近似单次散射，支持太阳方位/高度、浑浊度、Rayleigh/Mie 强度及亮度。太阳角度使用度，方位绕世界 Y 轴。开启后优先显示程序天空；原有 `.env`/`.hdr` 仍用于 IBL，但不再显示环境天空盒。

太阳的视觉方向不会自动修改方向光，也不会重新生成 IBL。应结合实际灯光和匹配的环境资源布置昼夜场景。天空和雾参数随项目保存；关闭/停止会清理天空材质并恢复场景原雾设置。

## 景深

对焦距离使用世界单位，焦距使用毫米，f-stop 越小景深越浅。低/中/高档位调整景深采样质量，保留作者选择的启用状态与镜头参数。

景深在主视图的最终调色之前运行；门内不重复执行景深。最终门面作为主视图深度参与模糊，无法按门后各个物体的虚拟深度分别对焦。自建深度目标随关闭释放；已有外部深度目标保留。

## GPU 粒子

既有 `visuals.createParticles()` 默认继续使用 CPU。显式选择 `auto` 或 `gpu` 时，支持 WebGL2 GPU 粒子的设备使用原生 GPU 模拟，否则回退 CPU。可以用句柄的 `backend` 查看实际选择。

```js
const sparks = visuals.createParticles({
  backend: 'auto', capacity: 512, rate: 70,
  lifetime: [0.8, 1.8], size: [0.015, 0.045],
  position: { x: 0, y: 1, z: 0 },
  emitBox: { min: { x: -0.2, y: 0, z: -0.2 }, max: { x: 0.2, y: 0, z: 0.2 } },
  velocity: { min: { x: -0.2, y: 0.3, z: 0 }, max: { x: 0.2, y: 1, z: 0 } },
  gravity: { x: 0, y: -0.3, z: 0 },
  colors: ['#FF8C40', '#FFF0C8'], blendMode: 'additive',
  angularSpeed: [-1, 1],
});
console.log(sparks.backend);
```

支持普通透明、加法和乘法混合。方向和发射盒在显式后端下遵循原生发射器空间；旧脚本未指定后端时保留原来的世界速度行为。重力使用世界方向。默认每系统容量上限为 10,000，可通过既有 `visuals.setLimits()` 调整。

暂停冻结模拟，时间倍率由场景时钟统一处理。`stop()` 停止发射，`destroy()` 释放资源；脚本、挂载实体或所借贴图销毁后相应资源也释放。没有提供贴图时使用自有白色四边形纹理。发光粒子不会自动成为灯光；门内粒子受已有画质设置控制，平面捕获不渲染粒子。

## 屏幕空间反射

SSR 使用深度、法线和材质反射率追踪屏幕内的反射，作用于主视图。参数包括最大步数、像素步距、距离、厚度容差、强度、粗糙度和模糊预算、下采样比例。低/中档关闭，高档开启 128 步；手动配置最多 256 步。

SSR 与 AO 复用几何缓冲。反射着色保持线性，再由主相机统一曝光、调色和转换。射线未命中时保留当前材质的 PBR 结果，因此仍能使用局部探针、平面反射或全局 IBL。WebGL2/MRT 不可用时跳过 SSR。

屏幕外、被遮挡以及几何缓冲未记录的透明物体无法由 SSR 重建，边缘也可能出现淡出或缺失。使用局部环境探针和适当粗糙度提供稳定的基础反射。SSR 不在每层传送门里重复执行；降低 SSR 分辨率减少射线和模糊工作，但不等于几何缓冲按同样比例缩小。

## 平面反射

先在画面设置开启平面反射，再在网格/模型属性中指定反射面。反射面以**节点本地空间**的法向轴和偏移定义：水平地面通常用 Y 轴、偏移 0；单位立方体顶面用 Y 轴、偏移 0.5。旋转节点可以改变反射方向，平面跟随父级、移动、旋转和缩放。它适合平面地板、水面和镜面，不能替代曲面立方体反射。

反射面朝本地正法向一侧显示。场景按可见投影面积排序，并限制捕获数、分辨率比例和总像素。每个主帧只捕获一次；不可见或预算不足的面恢复原材质的探针/IBL，闲置目标释放。支持自有材质、默认节点材质和常见导入 PBR/Standard 材质；共享材质生成轻量变体，扩展 PBR 参数与纹理保持共享。

捕获排除所有其他反射面、传送门门面、粒子和编辑标记，以控制递归与反馈。镜面使用主相机视点捕获；门内复用这份捕获，不额外为每个虚拟相机刷新镜面。反射模糊和强度可按节点设置，最终效果也受材质粗糙度和场景环境亮度影响。

像素预算按捕获目标的 `width × height` 计算，不代表全部显存；Mipmap、模糊和几何缓冲还有额外开销。运行时复用上一轮的投影/裁剪/预算批次，候选达到既有 `renderCompute.viewsMinPortals` 阈值时使用 WASM，小批次走 JS。镜面着色和捕获继续在 GPU 执行。

## 高级 PBR 材质

| 能力 | 控制 |
| --- | --- |
| 清漆 | 强度、粗糙度、独立清漆法线及强度 |
| 织物光泽 | 颜色、强度、粗糙度 |
| 各向异性 | 强度、切线方向旋转（弧度） |
| 环境透射 | 强度、IOR、厚度、吸收颜色及距离 |
| 细节 | 平铺倍数、明暗/法线/粗糙度混合强度 |
| 透明 | 自动、不透明、裁切、混合，以及裁切阈值 |
| UV/法线 | 偏移、旋转（弧度）、法线强度；零强度禁用法线影响 |

各向异性需要有效 UV 和切线基，设备可使用导数重建切线；缺乏相应数据的模型应在 DCC 中修复。透射采样项目环境贴图并模拟厚度吸收，**不会折射屏幕后方实际几何**。需要直接透出后方几何时可以使用透明混合，但这不提供真实几何折射或多层透明排序。

扩展贴图通道如下：

| 贴图 | 通道与颜色空间 |
| --- | --- |
| 清漆 | R 强度，G 粗糙度，线性 |
| 清漆法线 | RGB 法线，线性 |
| 光泽 | RGB 颜色（sRGB），A 粗糙度 |
| 各向异性 | RG 方向，B 强度，线性 |
| 透射遮罩 | R 强度，线性 |
| 厚度 | G 厚度，线性 |
| 细节 | R 明暗，A/G 法线 XY，B 粗糙度，线性 |

细节图的明暗和粗糙度以 0.5 为中性；平面法线的 A/G 应为 0.5。UV 变换作用于表面贴图；Lightmap 使用自己的 UV 通道，不继承偏移/旋转/平铺。所有引用贯通资源删除保护、撤销、项目保存、剪贴板、预制体与独立包分块加载。

这些扩展针对编辑器自有 PBR 材质。运行时 `visuals.createMaterial()` 的既有 StandardMaterial 接口保持原用途，适用于光束、贴花和简单动态几何。

## 示例、诊断和验证

导入 `examples/advanced-rendering-lab.arkglide` 查看程序天空、雾、景深、GPU 粒子、镜面地板和不同材质层。点击画面后按 1/2/3 切换低/中/高档，高档开启 SSR。这是使用程序资产的技术样例，材质与灯光仍需按具体游戏美术设计。

诊断显示大气/景深/SSR 状态、平面反射数与像素、GPU/CPU 粒子系统数量，并保留原有绘制调用与可选 GPU 时间。正确性验证使用 Chromium/SwiftShader，不能据此推断目标设备帧率。详情见 `verification/advanced-rendering.json`。

```sh
npm run example:advanced-rendering
npm run test:advanced-rendering:browser
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser
```
