## 浏览器回归同步修正

重新播放会回收旧沙箱，以释放浏览器 ES 模块文档缓存。测试必须在新沙箱安装加载延迟、等待真实加载开始后再停止，并等待脚本初始化后读取数组，不能用旧文档的数据或固定睡眠替代状态判断。保留旧测试的实体隔离、取消加载、共享模块状态和错误定位断言。

## 实测摘要

数据由打包前脚本从原始 JSON 生成在 `verification/summary.json`：

- 0.5/1/2 倍速实测频率及最大音高误差。
- 第 6 次到第 20 次停止后的 JS 堆、backing storage、embedder heap 首尾差值。
- Jolt WASM 堆容量稳定性。该容量保留不表示物理对象仍存活，不能要求其变为 0。

阈值为三个内存类别各增长 <2MiB，以及预热后 Jolt 容量不增长。整个项目仍有浏览器、编辑器和引擎的常驻内存。

## 待人工完成：真实手柄

记录设备型号、操作系统、浏览器版本、mapping、测试日期和结果。以下项目未在本轮真实设备上验证：

1. 在播放前连接手柄，再在播放中连接另一只；`input.gamepads()` 能报告设备。
2. 测试左右轴、正负方向、按钮跳跃；小于死区的轴不漂移。
3. 手柄与键盘同向取最强值，反向互相抵消；同时触摸移动/跳跃不丢指针。
4. 持续移动时拔掉手柄、切换窗口、失焦，再恢复；动作不会持续卡住。
5. 暂停菜单用方向键/手柄方向按钮移动焦点，用 A 激活；菜单不误触角色跳跃。
6. 改绑、冲突拒绝、恢复默认、保存/导出/导入后重复以上测试。

手机多指触控、横竖屏、实际音频输出延迟与目标格式亦建议在目标设备上人工复核。

## Windows CMD 复现

逐条执行：

```cmd
npm ci
npm test
npx playwright install chromium
npm run test:browser
set NODE_OPTIONS=--max-old-space-size=6144
npm run build
```

自定义 Chromium 路径只用于本地受限环境，不写入默认项目配置。CI 失败保留 trace、截图和 HTML 报告；音频/内存 JSON 作为独立测量 artifact 保留 7 天。
