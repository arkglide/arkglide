# 实时反射、时间抗锯齿、场景折射与扩展体积大气

本轮实现对应此前剩余列表的 1、2、5、6。共用配置、编辑器、脚本类型、项目保存和独立导出均已接入。示例是 `examples/rendering-completion-lab.arkglide`；`npm run example:rendering-completion` 可重新生成。

示例快捷键：`1/2/3` 切换质量，`T` 切换 TAA，`C` 切换云层，`L` 切换局部体积灯，`R` 切换场景折射，`O` 切换分层透明。场景同时包含金属/清漆、两层玻璃、交叉透明面、移动发光物和 GPU 粒子。

## 实时立方体反射

「局部反射探针」增加静态/实时模式。静态继续引用预过滤 `.env`；实时无需贴图，可指定 `.env` 作为首次捕获和设备回退。全局环境也可作回退。位置/盒尺寸、优先级和亮度沿用旧配置；新增 `resolution`、`interval`、`blendDistance` 与捕获 `layerMask`。

每个活跃实时探针拥有两份立方体纹理。六面分帧捕获，最后一面生成 mip 链后原子发布；后台未完成的立方体不会交给材质。原生 GPU 实时 GGX 过滤处理当前反射的粗糙度；旧/新捕获按时间插值，盒边界以世界空间距离混合到次选探针或全局环境。旧捕获在过渡结束前不会重写。清漆同样经过反射混合；材质和 KTX2 法线贴图共享原有资源，不为每个探针复制贴图。

`realtimeProbes` 限制活跃数量、每帧面数和像素数；捕获分辨率会向下调整到可容纳的二次幂。活跃探针按优先级、相机距离、ID 选择；活跃集合内轮流提交面。最多 32 个定义、8 个活跃探针、每帧 6 面。诊断报告实际捕获面/像素、完整更新次数、等待/回退数量及双缓冲 mip 存储估算。静态实例仍保留探针项目的保守回退。

捕获只包含不透明/裁切几何和天空，不递归捕获粒子、透明/透射、传送门、平面反射、SSR 或体积后期。捕获期间恢复基础材质，隔离反射反馈；用现有 RenderBatch/WASM 批量筛选适合的几何，少量对象沿用 JS/原生保守剔除。GPU 捕获和过滤不搬到 WASM。

```js
rendering.setRealtimeProbeBudget({ facesPerFrame: 2, maxPixels: 131072, transition: 0.25 });
rendering.refreshProbes('live'); // 请求完整更新，仍遵守捕获预算及旧缓冲过渡保护
```

## 运动向量、TAA 与重投影

抗锯齿下拉框选择「TAA（运动重投影）」。使用 Babylon 原生浮点线性速度缓冲、材质 Halton 抖动和双历史纹理，对支持原生速度的相机、网格、骨骼及实例进行历史重投影。自有 resolve 保留 HDR 邻域范围，裁剪 3×3 邻域历史，丢弃屏幕外历史，并随速度提高当前帧权重。

首帧、分辨率/相机/投影变化、长暂停或镜头跳切会重置历史；跳切距离/角度可调。`factor` 是当前帧权重，越小越平滑，快速细节更容易拖影。质量档位保留用户选择的 TAA。缺少 WebGL2、浮点 MRT 或纹素获取能力时回退 FXAA，并报告 `taaSupported`。

TAA 必须位于主视图后期链首位。SSR/AO、TAA 与透明剥离共用原生 prepass；景深、体积和色彩链按现有顺序合成。离屏捕获关闭抖动和 prepass 历史写入：仅设置 `noPrePassRenderer` 不足以阻止原生材质推进 `previousWorld`，会让主视图物体速度变零。探针、折射、镜面和传送门都经过同一隔离路径。抖动材质管理限定在自己的场景。

```js
rendering.setAntialiasing('taa');
rendering.setTemporal({ samples: 8, factor: 0.1, clampHistory: true });
rendering.resetHistory(); // 脚本瞬移或更换外观后可显式调用
```

这是时间抗锯齿，不是时间超分。透明/粒子和自定义 ShaderMaterial 可能缺少逐物体速度；邻域裁剪抑制拖影，不能补全没有输出的速度或不可见区域。体积位于 TAA 后，当前不单独累计体积历史。

## 场景折射与分层透明

材质「透射来源」可选环境贴图或场景折射；场景来源还需在画面设置开启「场景折射捕获」。保留 IOR、厚度贴图、吸收、法线、清漆和粗糙度，通过 HDR 投影纹理真正采样背景几何。

每帧按相机距离从远到近捕获有限的折射背景层；一层只读取已完成的更远折射层，排除自身及更近层，避免读写同一纹理和无限递归。相同材质的不同节点有独立层变体；只共享材质的原始资源。全局 `maxLayers`、`scale`、`maxPixels` 限制总开销；像素预算分配给全部活跃层，同一层每个主帧只捕获一次。超出层数的对象回退环境透射。

「分层透明」独立启用 Babylon 原生双向深度剥离，对支持原生 OIT 的透明片元按深度合成，减少交叉透明面的排序错误。`layers` 是剥离轮数，上限 8；超出可剥离深度的内容受原生剩余混合限制。没有所需 HDR/MRT 能力时保留排序透明，并在诊断报告支持状态。

```js
rendering.setRefraction({ enabled: true, maxLayers: 4, scale: 0.5, maxPixels: 1048576 });
rendering.setTransparency({ enabled: true, layers: 4 });
```

场景折射是有限的屏幕投影背景捕获，不能取到屏幕外内容；相互穿插的折射实体仍受对象距离排序近似限制。OIT 的片元排序适用于透明合成，不等同于任意多次光线折射。捕获不含粒子和体积后期，避免重复积分；多层成本由显式预算控制。

## 云层、局部体积灯与多阶散射

云层与高度雾在同一 GPU 路径累计透射。世界空间三维分形密度、垂直高度包络、细节侵蚀和风形成云体；视线与云层求交并由不透明深度截断，沿太阳光路额外采样形成云内自遮挡。高度雾和云层重叠时联合计算消光，近雾区间之后继续云积分，避免重叠区计算两次。

局部体积灯选择最近/较强的有限个点光或聚光灯，计算距离衰减、有效范围、光色和聚光内外锥的平滑衰减。聚光灯已作为完整场景节点接入：`lightType: 'spot'`、`lightRange`、`spotAngle`、`spotInnerAngle`，方向为节点本地 `-Y`，可用节点旋转控制。旧项目默认局部体积灯数量为 0。

`multipleScattering` 与 `scatteringOrders` 提供最多四阶的近似：后续阶数逐步降低消光/方向性及能量，在浓云和暗部补偿散射光。这是有界的多次散射近似，不是完整路径积分。方向光遮挡复用原独立稳定深度图，云有光路自遮挡；局部灯当前按范围/锥角散射，没有独立的局部体积阴影图。彩色透明体积阴影仍不支持。

```js
rendering.setClouds({ enabled: true, base: 80, thickness: 35, coverage: 0.65,
  density: 0.08, windX: 1, windZ: 0.3, steps: 48, lightSteps: 4 });
rendering.setVolumeLighting({ maxLocalLights: 4, localIntensity: 1,
  multipleScattering: 0.35, scatteringOrders: 3 });
```

云和雾共用体积分辨率/像素预算，保留深度引导边缘合成。云步数、光路步数随质量档位调整；暂停/时间缩放同步冻结/缩放风。当前对主相机积分，反射和门内没有独立体积路径。云设置单独开启时也能运行，无需开启高度雾。

## 检查范围

按用户要求只运行 3 项定向单测、1 个组合独立浏览器场景和类型检查；没有运行全量单测、完整编辑器/静态套件或生产构建。组合场景实际读取速度缓冲和立方体颜色，比较云、局部灯、多阶散射、折射的像素变化，检查捕获预算、暂停、镜头跳切、GPU 粒子、High/Low/High、停止资源及本地请求。记录见 [verification/rendering-completion.json](verification/rendering-completion.json)。软件 WebGL 不作为目标显卡帧率证明。
