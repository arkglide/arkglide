## 当前边界

自动视觉/物理切孔支持 static / kinematic / dynamic BOX 平板，包含旋转墙面、地面和天花板；不支持任意曲面或骨骼网格 CSG。宿主缩放固定，不能同时注册为 traveler。

关节连接物体采用原子整组穿越，保留原生固定、铰链、滑动和距离关节，整组提前完全退出。全部成员须为 dynamic；固定世界锚点及未注册端点会阻止穿越。尚未实现链节逐个穿门、两端长期分处不同空间的持续关节求解。

跨门接触使用原生形状查询与独立冲量桥接，尚未覆盖商业引擎的完整跨门多接触流形/事件求解。极端物体堆叠及长时间实机游玩还需进一步验收。因此此次交付是通用 API 与主要传送门机制扩展，不能宣称与 Portal 2 全部行为完全等价。
