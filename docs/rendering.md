# 画面与光照

在「菜单 → 项目设置 → 画面与光照」配置阴影、环境光照、色调映射和 AO。旧项目不自动开启新增效果。编辑器、播放预览与独立游戏共用实现。

## 灯光与环境

开启实时软阴影后，方向光和点光源按场景顺序使用阴影灯数量预算。网格/模型和灯光属性中的「投射阴影」，以及网格的「接收阴影」控制参与对象。方向光的柔和/接触渐变分别使用 PCF/PCSS；点光源和 WebGL1 回退 Poisson。阴影距离控制灯光深度范围，不能替代场景大小和灯光布局设计。

导入预过滤 Babylon `.env` 或 Radiance `.hdr` 环境贴图后可配置环境亮度、旋转和天空盒。HDR 在加载时转换为 128 像素立方体并预过滤；发布建议事先制成 `.env`，避免启动时转换。支持标准 `-Y +X` Radiance RGBE。资源保存在项目内，独立包自动预加载；替换和停止会清理纹理与对象 URL。

## 烘焙光照与环境遮蔽

材质编辑器新增 AO 贴图、AO 强度、烘焙光照贴图、强度和 UV 通道。

- Lightmap 使用**线性数值**，UV2 为默认；在 Blender 等工具中烘焙并导出带第二套 UV 的 GLB，再导入 Lightmap。引擎不自动烘焙、不生成 UV2、不自动打包光照图集。多物体图集需要相应 UV 已位于正确区域。
- 无 UV2 会在控制台提示；只有确实使用第一套 UV 制作的贴图才应选择 UV1。Lightmap 不继承基础色贴图的平铺比例。
- AO 使用线性灰度，主要压暗环境/间接光，不会无条件压暗直射光。场景设置中的 SSAO 需要 WebGL2/MRT；不可用时保留材质 AO，跳过屏幕效果。
- 灯光烘焙中的直射和运行时直射应合理分工，避免把同一盏灯重复叠加。

## 局部反射探针

先导入房间的预过滤 `.env`，再在项目设置中添加探针。中心和范围使用世界坐标，范围是盒子的完整宽/高/深。探针对引擎自有 PBR 材质生效，包括模型部件上分配的自有材质；导入模型原始材质保持原样。

物体世界包围盒中心进入范围时使用局部立方体投影。重叠范围优先级高者优先，相同优先级选择体积小者，再按 ID 排序。离开范围恢复全局环境。共享材质按探针生成轻量变体并共享贴图，防止不同房间相互串用反射。亮度乘在全局环境亮度之上；边界为离散切换，不进行探针混合。最多 32 个探针；本轮使用预烘焙环境，不逐帧捕获动态立方体。

所有引用贯通撤销、项目保存、恢复和独立包；仍在使用的环境、AO 或 Lightmap 无法直接删除。
