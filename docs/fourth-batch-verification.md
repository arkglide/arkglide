## 覆盖内容

- 二进制编码保持 Unicode、双精度及负零，拒绝越界、坏引用、重复键、尾部字节和超出预算的数据；SHA-256 与 Node 标准实现比对。
- 独立包没有完整 `project.json`。示例入口清单为 6,254 字节，包含 10 个资源、2 个模板、8 个脚本，共 71 份文件；完整资源索引在二进制分片中。
- 1 万节点、500 模板的数据用例，入口读取 1 个启动块和 79 个节点块；模板体在调用时读取。500 份相同模板节点只存一块。此为构建/加载器规模验证，未声称 1 万个带物理实体在浏览器达到目标帧率。
- 游戏脚本压缩后保留公共属性、原生模块导入绑定和动态导入行为，模块块中不保留原始 import/转导出路径、注释、局部变量名或 source map。传统实体脚本仍按所属脚本注入 API。
- 保存配置经过项目规范化和 JSON 往返仍控制导出；缺失/非法预加载资源在打包阶段拒绝。
- 初始入口不读未使用模板体与模板专用模型；相同资源共享，多个租约中释放一个不影响另一个，释放最后一个回收缓存，显式预加载模板保留至停止。
- 并行初始化失败后晚到的音频不能回写，取消启动清单、节点下载和 iframe 初始化后均不能复活旧会话；重新启动隔离模块状态。
- 编辑器通过真实模块 Worker 完成压缩并下载 ZIP，验证输出格式、开关默认值和设置重开保留；缺失模板模型阻止生成，编辑器运行期间禁用导出。

## 发现并解决

旧示例只在脚本中通过 ID 使用音频，已在 `settings.build.preload` 中显式声明；静态测试改为按实际二进制索引定位文件。并行测试曾触发软件渲染下的输入时序失败，补正诊断接口并等待单调递增的模拟帧时间，最终串行玩法回归全部通过。完整游戏工程依然需要合理划分关卡；当前不提供自动空间世界流送，代码保护也不提供客户端保密。
