## 处理过的故障

- 初期并行构建与浏览器运行时，构建被环境终止（137）；最终改为串行运行，并以 5 GiB Node 堆配置完成生产构建。交付记录只把最终成功构建列为通过。
- 初版静态测试共用同一单进程 Chromium 上下文，导致下一用例创建页面失败；改为各测试独立 project 后完整通过。
- 暂停宿主最初先显示暂停状态、再发送消息，存在异步时序窗口；改为以运行时统计确认暂停/继续，测试等待实际暂停后再检查冻结时间。
- 新增 early bootstrap 内联块后，旧运行时单测只提取第一块；测试加载器改为按真实文档顺序执行全部内联块，并新增 bootstrap 资源失败测试。
- 回归 trace 显示功能断言全部完成，卡住的是 context.close；移除 pagehide 中主动销毁 WebGL 引擎的逻辑后，原第三批、模块及全量回归正常完成。正常停止仍完整清理，并销毁运行 realm。
- 开发过程中的未完成/被中断测试没有作为通过的最终验收。未把异常或模拟测试写成真机验收。
