# 独立游戏打包变更

当前默认输出升级为 `arkglide-static-2`。原项目档案及编辑器预览协议保持兼容。

- 完整 `project.json` 改为字典编码的二进制节点块、定义、模板和分片索引，内容寻址去重资源；启动只读取入口依赖。
- 用户脚本在构建期验证并转换为模块，静态引用预计算，动态导入延迟加载；默认压缩、局部变量改名、移除注释与源文件名。
- 构建和 ZIP 压缩移入 Worker，可取消；先得到可下载结果，再执行下载。设置随项目保存，CLI 共用相同配置。
- 独立页自动启动并全屏显示游戏，启动显示终端日志，进入后清空；移除调试工具栏和进度条，游戏日志默认关闭。
- 新增 `assets.load()` 租约接口，预制体/关卡加载自动获取依赖，销毁实例释放缓存；取消、错误、停止及重启隔离会话。
- 增加二进制格式、配置持久化、损坏文件、并行失败、延迟资源释放、实际浏览器加载和编辑器 Worker 打包回归。

主要实现位于 `src/export/`、`src/engine/binary-runtime.js`、`src/engine/package-runtime.js`、共享运行页和独立宿主。具体使用与边界见 [打包与部署](fourth-batch.md)，结果见 [验证记录](fourth-batch-verification.md)。
