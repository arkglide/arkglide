# 大气、反射与材质扩展计划

起点：`28ec019`。沿用上一轮共享渲染管理器，按以下顺序实施、验收和提交，完成后直接推送 main。旧项目默认保持原画面，所有新增效果可以关闭。

## 一、大气与特效

- 项目设置支持线性、指数和指数平方雾，颜色、距离和密度可保存。
- 程序天空支持太阳方位/高度、浑浊度、Rayleigh/Mie 散射；与已有环境天空盒互斥，天空不替代用于材质光照的 IBL。
- 主相机景深支持焦距、光圈、对焦距离和质量档位，在最终调色之前处理；门内复用主视图后处理，避免重复模糊。
- 粒子增加 GPU/自动后端、重力、发射盒、混合方式和旋转速度；设备不支持时回退 CPU，保留既有脚本和所有权清理。
- 验收：真实 WebGL 雾/天空/景深像素差异；GPU 粒子真实发射、CPU 回退、暂停和销毁；设置撤销、保存与独立导出一致。

## 二、反射系统

- 主相机 SSR 支持步数、距离、厚度、粗糙度模糊、分辨率和模糊预算；设备不支持时保留 IBL/局部探针。
- 网格/模型支持跟随世界变换的平面反射，按本地法向定义镜面；控制反射分辨率、模糊和强度。
- 场景提供平面反射数量/像素预算，避免反射面互相递归采样；闲置和已删除目标释放，共享源材质隔离。
- 保留线性 HDR/最终调色约定；明确 SSR 看不到屏幕外对象、平面反射与传送门的边界。本轮保留预烘焙局部探针，不新增实时六面立方体捕获。
- 验收：实际镜像几何、移动/旋转镜面、SSR/探针共存、预算、反复启停与资源释放。

## 三、材质能力

- 自有 PBR 材质增加清漆、织物光泽、各向异性、基于环境的透射/厚度吸收，以及细节贴图。
- 增加法线强度、透明模式/裁切阈值、UV 偏移与旋转；支持扩展贴图的正确色彩空间。
- 编辑器材质面板提供对应控制，模型材质槽继续可用；引用贯通校验、删除保护、剪贴板/预制体和静态资源分块。
- 验收：真实 Babylon 参数和 WebGL 材质差异，贴图替换不泄漏，环境透射/透明裁切正确，保存与独立包资源依赖完整。

## 性能和最终回归

- 像素着色、景深、SSR 和粒子模拟优先使用 GPU；适合批量计算的 CPU 工作继续复用已有 WASM 预算/几何模块，不为简单标量配置增加跨边界调用。
- 新增效果纳入画质档位和诊断，完整检查能力回退和生命周期。
- 提供组合示例与使用说明；固定源码后串行执行浏览器测试，避免 CLI 同步运行时引起开发服务器热更新。完成单测、类型检查、WebGL、独立包与生产构建后提交推送。

## 实施记录

- 第一阶段完成：原生大气雾、无外部纹理的散射天空、主视图景深和 GPU/CPU 粒子后端。雾/天空/昼夜/景深均有 WebGL 像素差异；GPU 粒子真实发射，暂停冻结，销毁释放。景深创建的深度目标按所有权释放；14 项相关单测、2 项 WebGL 用例及类型检查通过。
- 第二阶段完成：线性 HDR SSR、随本地平面变换的镜面反射，复用已有 JS/WASM 投影与预算调度。SSR 与 AO 共享几何缓冲；自建资源清理、借用缓冲保留。平面反射显式调度，排除其他镜面和门面，避免递归和重复捕获。10 项渲染单测和 3 项 WebGL 用例通过，验证实际反射、镜面变换、像素预算和材质隔离。
