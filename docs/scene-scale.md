# 静态几何与资源预算

重复的基础几何默认共享 GPU 顶点/索引缓冲，每个节点仍有独立变换、材质、拾取、物理和销毁生命周期。在网格属性关闭「共享重复基础几何」可取得独立几何。烘焙生成 UV2 时也会先取得独立几何。共享缓冲不会自动合并绘制调用；自动实例批次和深度遮挡剔除仍是后续功能。

## 静态 LOD

在网格/模型属性启用「静态几何 LOD」，设置距离和网格精度。距离为世界单位，按当前实际渲染相机选择层级；较小的网格精度产生更粗的远景。可配置 1–3 级，距离必须递增，精度为 2–128 的整数。编辑器提供两级默认值，JSON/API 可保存其它有效层级。

简化采用保留法线与 UV 分区的顶点聚类，计算优先用已有 C++/WASM 模块；不可用时使用 JS。它适合远景代理，不保证保留小孔、薄片和全部拓扑，不提供固定减面百分比。烘焙对象、带 Lightmap 的材质、骨骼/morph、顶点色、实例、多材质和带脚本/动画/角色/动态物理的对象保留原网格；少于 128 个三角形或超过 10 万顶点也保留原状。没有减面收益时不安装额外层级。

同源几何与相同精度的 LOD 共享简化结果和 GPU 几何，保留每个对象的材质。反射材质变体在捕获前同步。碰撞、拾取和实体包围盒继续使用原始几何；LOD 仅影响绘制，不能用它改变游戏规则。关闭、删除、替换模型或停止后移除对应层级。

运行诊断中的 LOD 网格/层级、跳过数量和 WASM/JS 构建次数可用于确认实际启用。首帧生成不计入稳态性能；大型模型仍应提前制作和检查远景资产。

## 资源检查

停止运行，打开「菜单 → 资源预算检查…」并扫描，可以下载 JSON。报告包含：

- 源网格和三角形、独立/共享几何、顶点与索引估算、最大的 20 个网格。
- 模型/贴图文件字节、真实图片尺寸、RGBA8 全 Mip 链估算，以及缺失数据与图片解码错误。
- 相同 SHA-256 文件字节的引用组，便于整理重复导入；它不自动合并用户资源。
- 当前 LOD 构建诊断。

静态贴图估算不包含环境立方体、阴影/反射/后处理目标、MSAA、压缩格式实际占用和驱动开销。源三角形数不是某个相机实际绘制的三角形数。默认 256 MiB 提醒用于发现大资源，实际预算应通过目标设备实测确定。

扫描可取消；场景、资源或项目改变后拒绝应用过期报告。KTX2/Basis 压缩贴图与解码器随独立包分发尚未在这一阶段实现。
