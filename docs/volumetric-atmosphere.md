# 体积大气

在「项目设置 → 画面与光照 → 大气与景深」开启「体积大气（主视图）」。旧项目默认关闭；生效时替代距离雾。没有可用 WebGL2/HDR 渲染目标时保留距离雾，诊断面板显示设备不支持。

体积雾在 GPU 上按主相机深度沿视线积分，使用 Beer–Lambert 透射、Henyey–Greenstein 单次散射和可选世界空间密度噪声。高度密度为 `density * exp(-max(0, y-height) * falloff)`；基准面以下不继续指数增浓。提高基准高度会抬高雾层，增大衰减使雾更贴地。积分距离是从近裁剪平面起的世界距离，远处天空也受雾影响。

首个启用且强度大于零的方向光提供颜色、强度和世界方向。开启「方向光体积遮挡」后，独立的正交深度图让不在屏幕里的物体也能遮挡光束。光空间中心按纹素稳定；不会替换表面阴影生成器，兼容原有级联阴影。体积深度范围之外按未遮挡处理，扩大范围会降低同一分辨率下的光束边缘精度。节点 `castShadows: false` 同样排除体积遮挡。局部点/聚光散射及多阶散射近似现已支持，见 [扩展体积大气](rendering-completion.md#云层局部体积灯与多阶散射)。方向光的物体包含/排除列表、彩色透明阴影仍未支持。

「雾环境亮度」提供无方向的填充，「雾方向光强度」调整散射亮度；方向性为零时各向同性，正值增强朝向光源观察时的光晕。噪声固定在世界空间，没有每帧随机闪烁或模拟时间推进。天空的太阳参数继续独立控制视觉太阳，需要手动与真实方向光方向匹配。

## 质量与预算

| 档位 | 积分步数 | 分辨率比例 | 积分像素上限 | 光深度图 |
| --- | ---: | ---: | ---: | --- |
| 低 | 16 | 0.25 | 262,144 | 关闭，保留高度雾 |
| 中 | 32 | 0.5 | 1,048,576 | 512² |
| 高 | 64 | 0.75 | 2,097,152 | 1024² |

切换档位保留体积开关与雾色、密度、高度、散射等创作参数。自定义最高 96 步和 4,194,304 积分像素；窗口、高 DPI、渲染比例变化时按实际尺寸重新分配，且遵守设备纹理尺寸限制。诊断显示的是实际积分宽高、步数、方向光和光深度图尺寸。

低分辨率积分结果经深度引导合成后进入 Bloom、景深和最终调色。薄前景没有相近深度样本时保留源颜色，避免借用后方浓雾；这会使亚像素物体的雾略少。主视图仍有一张全分辨率深度图和保留线性颜色的后处理目标，积分像素上限不是全部显存上限。增加步数只改善射线分段精度，优先尝试中档，再按目标显卡实测选择。

GPU 着色承担积分和噪声计算；WASM 继续处理已有批量几何/剔除计算，避免将逐像素工作搬回 CPU。

## 脚本与示例

```js
rendering.setVolumetric({ enabled: true, density: 0.045, height: 1, falloff: 0.16 });
rendering.setVolumetric({ shadows: true, steps: 48, scale: 0.5 });
const settings = rendering.getSettings().volumetric;
const stats = rendering.getStats();
console.log(stats.volumetricPixels, stats.volumetricShadowSize);
```

补丁经过完整范围校验；出错时保留原设置。参数只影响当前运行会话；持久保存请使用项目设置。

导入 [volumetric-lab.arkglide](../examples/volumetric-lab.arkglide) 查看柱廊、屋顶缝隙和斜射光束。`V` 对照开关，`1/2/3` 切换质量，`4/5` 对照贴地/高处视角。几何与小型 HDR 环境随项目打包，无外部美术资源。

## 边界

- 当前只对主相机积分。传送门按主视图门面深度、镜面按反射面深度参与合成，里面的远景没有独立的体积路径。
- 透明物体使用后方不透明表面深度；裁切材质沿用原生深度渲染的 alpha test。半透明粒子、玻璃和多层透明没有各自的雾透射积分。
- 现已支持体积云、局部灯散射和多阶散射近似；体积自身的时间累计、局部体积容器、完整物理大气和动态 GI 仍未支持。详见 [渲染补全](rendering-completion.md)。
- 软件渲染验证画面与预算分配，不证明真实设备帧率。使用目标机的场景性能基准采集实际 CPU/GPU 时间。
