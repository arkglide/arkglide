## 源码审查结论

- `public/runtime.html` 已可加载本地 Babylon、内嵌数学/Jolt WASM，但启动入口依赖编辑器 postMessage，脚本 URL 为站点绝对路径。
- `RuntimeFrame.tsx` 提供启动快照及 model/texture/audio ArrayBuffer，并在重复运行时重建 realm；独立包需同样回收模块映射。
- `projectExport.ts` 导出可再编辑的项目档案，不提供部署页/运行时，不是 F13。
- `contentResources.ts` 采集场景与所有预制体模型；编辑器 glTF 导入会将关联文件内嵌。独立导出需检查二进制是否真的自包含，不能仅相信文件名。
- `module-runtime.js` 支持静态 import/export、转导出、字面量 import()；变量路径、循环、远程/npm 导入、顶层 await 未支持。导出应在不执行用户脚本的情况下验证模块图。
- 场景、物理、声音、输入、生命周期和预制体已有 dispose/stop/generation 边界；独立宿主还需取消网络与销毁 iframe realm。
- 数学/Jolt 当前采用 SINGLE_FILE，WASM 在 JS 内嵌；不能只寻找 .wasm 文件就认定丢失。
- 项目中包含材质、HUD 图片、音频、动画控制器、重定向及模板实例数据；必须整体保留。
