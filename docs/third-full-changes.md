## 启动与示例

要求 Node.js >=20.19.0。在 Windows CMD 进入项目目录后逐条执行：

```cmd
npm ci
npm run dev
```

打开编辑器并导入 `examples/third-full.arkglide`。示例包含斜坡、台阶、墙、移动平台、触发器、关节门、原生角色控制器、方向混合/跳跃、脚步事件、骨骼重定向、背景音乐、暂停混音、可改绑输入及浮动摇杆。点击播放后，用 WASD 移动、空格跳跃；暂停菜单提供音乐倍率与跳跃重绑定。运行时周期生成嵌套补给箱并回收旧实例。

底部「材质与预制体」内新增物理、动画控制器、音频混音器、UI 画布页签。选择场景实体后在属性面板设置组件。组件与项目资源必须使用已有名称/ID；非法引用在写入项目之前拒绝。

`npm run example:third` 可重新生成示例。重新生成前请保留你自己改过的示例。

## 运行隔离

再次播放会重载沙箱文档，使 ES 模块缓存随旧文档释放；停止后当前文档仍保留，便于检查清理结果。父页面以启动 token 和运行 ID 拒绝旧沙箱消息，停止或取消加载不能启动过期脚本。

停止时约束、角色、形状查询临时对象、调试网格、动画事件、音频节点/流/工作线程、UI 订阅、Blob URL 与输入捕获均应释放。Jolt 的 WASM 堆容量是分配器容量，不等于仍存活的物理对象数量。
