# 光照制作与大场景优化计划

起点：`57cac33`。按光照制作 → 几何与资源优化 → 性能验收顺序实现，逐阶段提交，验证后直接推送 main。

## 光照制作

- 编辑器增加选中静态对象的光照烘焙入口、分辨率/AO/偏移参数、进度与取消。工作线程执行计算，项目变更后拒绝应用过期结果，一次撤销恢复全部资源与材质绑定。
- 用 C++/WASM BVH 射线批次计算方向光、点光源的静态漫反射直射及环境遮蔽。输出线性 PNG 和亮度倍率，保存到项目已有贴图系统。基础几何自动生成第二套 UV；导入模型要求已有不重叠 UV2，明确检查错误。
- 每个接收对象使用独立自有 PBR 材质，保留原表面参数，关闭已烘焙材质的实时直射，避免重复叠加。静态几何、灯光或变换改变后显示重新烘焙提示。
- 为方向光增加可选级联阴影与级数、分割和混合设置，设备不支持时回退普通阴影。相机切换、画质切换与停止正确释放。
- 本轮烘焙是静态直射与 AO，不包含多次反弹 GI、纹理发光照明或骨骼/透明物体的烘焙。导入模型的 UV 展开仍由 DCC 完成。

## 几何与资源

- 对重复基础几何共享 GPU 几何资源，保留独立节点、材质、拾取与生命周期，避免复制顶点缓冲。
- 增加显式静态 LOD 配置；网格简化使用 C++/WASM，按当前渲染相机选择层级；保留原物理/拾取几何。变形、骨骼、morph、多材质等暂不支持的对象保守保留原网格并给出诊断。
- 编辑器提供资源预算报告：节点与三角形、重复几何、贴图尺寸/预估显存、文件字节和缺失资源。扫描可取消，不阻塞编辑。
- 本轮不把几何共享称为绘制调用合批；自动实例批次、深度遮挡剔除与 KTX2/Basis 管线另行实施。

## 性能验收

- 提供可直接打开的真实 WebGL 场景基准，包含重复场景、LOD 开关、轨迹、预热、固定采样窗口和 JSON 下载。
- 记录浏览器、分辨率、DPR、渲染器、软件/硬件识别、总帧/CPU/GPU 的中位数与 P95、绘制调用与三角形。无有效 GPU 计时时保留空值；页面隐藏/失焦或设备丢失中止采样。
- CLI 自动化运行相同基准，可指定本机浏览器；本环境的软件渲染结果只验证流程和正确性。真实显卡性能预算须由相同页面在目标硬件采集，不编造 60 FPS 达标结论。
- 增加光照/LOD 组合示例、单元与真实像素回归，检查保存、撤销、独立导出与多次启停；最后运行完整回归、类型检查和生产构建。
