# 静态实例批次实施计划

在体积大气交付后实施。目标是让重复基础物体共享一次实例绘制，同时保留各节点的身份、拾取、可见性、父子变换与静态碰撞。

- 网格属性增加显式实例批次开关；引擎按基础几何、自有 PBR 材质与阴影标记自动分组，使用原生硬件实例绘制。几何共享和实例合批分别统计，不把缓冲节省当作绘制调用下降。
- 编辑器与运行时使用同一构建路径。隐藏的批次源由场景适配器持有，成员删除不释放共享材质，最后一个成员删除后释放批次源；清空场景与反复启停不留内部对象。
- 首版保守回退模型、骨骼/变形、脚本/动画/动态物理、透明/透射、烘焙光照、局部探针、平面反射、负缩放以及已开启的静态 LOD。为不同实例选择独立 LOD/探针是后续组合能力。
- 材质、阴影开关或适用条件变化时重建正确分组。实例仍可独立移动、旋转、隐藏和拾取；不提供每实例独立材质参数。
- 接入项目校验、属性面板、脚本诊断和资源预算。批次开关默认关闭以保留旧项目对象类型；不支持硬件实例时保留普通网格。
- 验收：真实 WebGL 对照重复场景的画面与绘制调用；验证拾取返回原节点、单个成员隐藏/移动/删除、父级变换、阴影、材质改组、原始碰撞数据、独立导出和清理。继续使用已有 WASM 批量变换/剔除，实例矩阵提交使用 GPU 原生路径。
